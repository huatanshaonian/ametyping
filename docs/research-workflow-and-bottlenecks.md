# 工程导向科研的当前困境与文献工作流破局备忘

> 记录日期：2026-11-27  
> 适用方向：隐身飞行器气动/电磁耦合优化、等离子体鞘套电磁散射（RCS）、自研 Python + CuPy 向量化电磁求解器

---

## 1. 当前面临的真实困境

1. **与生物医药 / 开放 AI 学科的结构性差异**
   - 生物医药与主流 AI 方向拥有海量公开数据集、统一评测榜与极低的单次试错成本，容易形成“A 方法套 B 数据”的流水线产出；
   - 气动-隐身耦合与等离子体 RCS 属于高度封闭的工程学科：真实外形与实测数据（如暗室 RCS、再入飞行试验）极少公开，单次耦合计算成本高（网格 + 气动 + 电磁），且物理边界强约束（换一个 $ka$、$n_e/n_c$ 或马赫数，老方法就可能失效），无法无脑套模板。
2. **文献积压与高阅读摩擦力**
   - 截至 2026-11-27，系统候选池一度积压近 **900 篇**待选论文（`spare=498`, `inbox=416`），但真正收下精读的仅 **8 篇**；
   - 旧流程要求“先看长英文摘要 → 决定是否收进 Zotero → 等 PDF 与长卡片 → 自己回翻旧论文对照”，心理阻力极大，容易产生“欠债感”而索性不点开。
3. **“看文献”与“出研究思路”之间的断层**
   - 阅读文献同时承担两种完全不同的目的：
     - **拓展眼界**：需要快速看懂“别人在干什么、有什么新招”，低负担积累直觉；
     - **积累知识与迁移**：需要从少数高价值论文中提炼范式、对比适用边界，并快速复现/迁移到自己的求解器里。
   - 把两种目的混在同一条高门槛流程里，导致眼界没拓宽、范式也没提炼出来。

## 2. 工程导向科研的三类硬通货范式（结合自研 CuPy 求解器优势）

在封闭工程学科里，不靠涉密外形也能持续产出高价值工作的三条主线：

| 范式 | 核心套路 | 为什么适合当前家底 |
|---|---|---|
| **1. 失效边界与过渡区修正** | 精准标出高频法（PO/PTD/SBR）或简化等离子体模型在哪个无量纲区间（$ka$、$n_e/n_c$、攻角、曲率）失效，提出物理自洽修正，并用全波解/解析解做真值验证 | 直接对接 `kb_struct.sqlite` 的**矛盾与边界清单**；使用标准公开外形（球、柱、钝锥、飞翼、S 弯腔体）即可严格证伪 |
| **2. 求解器级耦合优化迁移** | 把伴随梯度（Adjoint）、多保真（高频打底 + 少量全波修正）或物理约束降阶（POD/ROM/算子学习）嵌进求解器内部，把优化维度从 10 维推到 100 维、耗时压低一个量级 | 多数研究者只能把 FEKO/Fluent 当黑盒调用；**自研向量化 CuPy 求解器**是稀缺的底层优势 |
| **3. 跨工况定量设计图谱（Design Map）** | 把前人散落甚至互相打架的工程结论，通过可复现基准算例与系统参数扫描，收束成清晰的物理规律与帕累托权衡拐点 | 工程顶刊极度重视可复现的系统性定量规律；所有算例天然配合 `.npz` 全量归档 |

## 3. AmeTyping 文献系统的“两级漏斗 + 零欠债”破局架构

为匹配“先 3 分钟快速看懂 → 仅对 5% 重火力提炼/复现/迁移”的节奏，系统按两级漏斗运转：

1. **第一级：零摩擦「快速看懂」（每日 3 分钟清零）**
   - **知识库反哺打分**：`feed.js` 每日打分自动注入 `kb_struct.sqlite` 中的跨论文矛盾主题与范式矩阵空白组合，优先把“补空白 / 碰分歧”的新论文推到前面；
   - **3 句话中文速览**：每篇推送直接给出「改了哪一招」「定量效果」「与你库里的关系」，无需先啃英文长摘要；
   - **三键分流**：
     - **`看懂了`（仅拓展眼界）**：不进 Zotero、不下载 PDF，留存 3 句话眼界笔记并立刻清零今日待办；
     - **`收下`（值得深挖）**：自动进 Zotero → 抓 PDF → 抽结构化证据表 → 生成带库内对照的深读卡；
     - **`跳过`**：淘汰并作为负样本降权同类论文；
   - **高分自动入库解读（`autoKeepMinScore`）**：达到阈值的高分论文自动收进 Zotero `每日文献` → 自动抓 PDF → 自动做深读卡 + 抽证据表，无需人工逐篇点审批；
   - **全量保留 `spare` 候选池**：不自动删除历史候选，保留全量素材供后续批量深读或按需检索。
2. **第二级：重火力「提炼范式 / 复现迁移」**
   - **深读卡自动对照库内 Top-5**：`cards.js` 生成深读卡时，自动用 2560 维向量找出本地最相似的 5 篇论文并拉取 `kb_struct.sqlite` 已核验参数，直接输出定量工况对比与可迁移点；
   - **基准复算闭环**：可复算的经典算例通过 `tools/benchmarks/`（Python + CuPy/NumPy）生成全量 `.npz` 并回写 `benchmarks` 表，用残差说话。
3. **下一阶段演进方向（高信息密度速览流 + 学术团队图谱）**
   - 先批量生成深读卡，再基于深读卡（而非薄摘要）提炼高信息密度速览；
   - 打造类 Twitter/X 信息流页面：图文卡片（关键裁图 + 一句话核心改动 + 量化效果）+ **大学/实验室/团队简介与网状关系标签**，按团队/高校追踪技术演进。
